# John Nigel Landingin — Developer Portfolio

A handcrafted, high-performance developer portfolio built to stand out from generic templates and AI-generated slop.

## 🛠 Tech Highlights
- **100% Vanilla & Lightweight:** Pure HTML5, Modern CSS, and Vanilla JavaScript. Zero runtime bloat, zero dependencies.
- **Authentic Engineering Aesthetic:** Editorial Swiss typography (`Space Grotesk`, `JetBrains Mono`, `Instrument Serif`), crisp 1px borders, and tactile micro-interactions.
- **Non-AI Copy & Real Case Studies:** Authentic architecture breakdowns of the C#/.NET Transport & Logistics Delivery Management System, Unity 3D enterprise showcase at Hexatronics, and municipal database pipelines.
- **Interactive Features:**
  - `Ctrl + K` / `⌘ + K` Command Palette
  - Dynamic local time in Tarlac City, Philippines (`Asia/Manila` UTC+8)
  - Dark / Light / Monochrome Terminal theme toggle
  - Architectural spec inspector modal
  - Instant one-click copy email with visual toast notification
  - Embedded real resume download (`assets/John_Nigel_Landingin_Resume.pdf`) and authentic portrait photo (`assets/profile.jpg`).

## 🚀 How to Run Locally

### Option 1: Direct in Browser
Simply double-click `index.html` or open it in Google Chrome / any modern browser.

### Option 2: Local HTTP Server (PowerShell / Python / Node)
Using PowerShell:
```powershell
# In the project directory:
Start-Process "index.html"
```

Or with Python:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.

## 🌐 How to Deploy for Free

### Deploy to GitHub Pages (Recommended)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```
2. On GitHub, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website will be live at `https://YOUR_USERNAME.github.io/YOUR_REPO/` within seconds!
